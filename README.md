# 🎲 Probability Simulation

A small Python project for simulating basic probability concepts using random experiments.

## ✨ Features

* 🪙 Coin Toss Simulation
* 🎲 Dice Roll Simulation
* 🎲 Two Dice Simulation
* 🥧 Monte Carlo Pi Estimation
* 📊 Comparison of Experimental and Theoretical Probability
* 🔢 Input Validation

## 🛠️ Technologies

* `Python`
* `random`
* `math`
* `Object-Oriented Programming (OOP)`

## 📁 Project Structure

```text
probability-simulation-py/
├── coins/
├── dice/
├── monte/
├── tools/
├── main.py
└── requirements.txt
```

## 🚀 Run

```bash
git clone https://github.com/Amirhosein-Rezaie/probability-simulation-py.git
cd probability-simulation-py
python main.py
```

## 🎯 Purpose

This project was created to practice Python fundamentals and understand probability through practical simulations.
